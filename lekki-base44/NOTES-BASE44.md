# Lekki — version Base44 (TanStack Start)

Application **Lekki AI** construite sur Base44, exportée telle quelle.

- Frontend : TanStack Start (React 19, routes dans `src/routes`), Tailwind CSS, shadcn/ui.
- Backend : server functions TanStack Start (`src/lib/server-fns.js`) + entités Base44 (`base44/entities`).
- Données : Base44 (Espace, Source, Conversation, Message, Note, Artefact).

Lancer : `cd lekki-base44 && npm install && npm run dev`.
